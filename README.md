# ShieldOps - Cybersecurity E-Commerce Platform 🛡️

ShieldOps is a secure, full-stack e-commerce web application built using **ASP.NET Core MVC**, designed for browsing and purchasing specialized cybersecurity products and tools.

---

## 🚀 Live Demo
You can view the live deployed application here:
🔗 [https://ecommerce-shieldops.onrender.com/](https://ecommerce-shieldops.onrender.com/)

---

## 🛠️ Tech Stack & Architecture

* **Backend:** C#, ASP.NET Core MVC
* **Database & ORM:** SQLite, Entity Framework Core (EF Core)
* **Authentication & Security:** ASP.NET Core Identity (Role-based access control supporting Admin and Customer roles)
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap, jQuery
* **Containerization & Deployment:** Docker, Render Cloud Platform

---

## ✨ Key Features

* **User Authentication & Role Management:** Secure login/signup system with automated role seeding for **Admin** and **Customer** roles.
* **E-Commerce Catalog:** Browse defensive security products and manage shopping features smoothly.
* **Admin Control Panel:** Dedicated administrative tools for managing store items.
* **Session Management:** Secure session tracking and cookie configurations for live environments.
* **Cloud Containerized:** Packaged with Docker for fast and reliable cloud deployment.

## ⚙️️ Local Installation & Setup

To run this project locally on your machine, follow these steps:

1. Clone the Repository:
   git clone [https://github.com/iqra-azam47/Ecommerce_ShieldOps.git](https://github.com/iqra-azam47/Ecommerce_ShieldOps.git)
   cd Ecommerce_ShieldOps

2. Open Solution:
   Open ShieldOps.sln in Visual Studio.

3. Run the Project:
   dotnet run --project ShieldOps/ShieldOps.csproj
